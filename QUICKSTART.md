# 🚀 Быстрый старт

## Запуск проекта

1. **Запустите сервер**:
```bash
python manage.py runserver
```

2. **Откройте в браузере**: `http://127.0.0.1:8000`

## 📚 Доступные страницы

### Frontend (HTML)
- **Главная**: `/` - Главная страница с популярными курсами
- **Каталог курсов**: `/courses/` - Список всех курсов с фильтрами
- **Детали курса**: `/courses/{slug}/` - Подробная информация о курсе
- **Мои курсы**: `/my-courses/` - Курсы, на которые записан пользователь
- **Вход**: `/login/` - Авторизация
- **Регистрация**: `/register/` - Создание нового аккаунта
- **Админка**: `/admin/` - Панель администратора

### API (REST)
- **Регистрация**: `POST /api/users/register/`
- **Вход (JWT)**: `POST /api/users/login/`
- **Курсы**: `GET /api/courses/`
- **Детали курса**: `GET /api/courses/{slug}/`
- **Записаться**: `POST /api/courses/{slug}/enroll/`
- **Мой прогресс**: `GET /api/courses/{slug}/my_progress/`
- **Мои записи**: `GET /api/enrollments/`

## 📱 API Примеры

### Регистрация нового пользователя
```bash
curl -X POST http://127.0.0.1:8000/api/users/register/ \
  -H "Content-Type: application/json" \
  -d '{
    "username": "newuser",
    "email": "newuser@example.com",
    "password": "securepass123",
    "password2": "securepass123",
    "first_name": "Имя",
    "last_name": "Фамилия",
    "role": "student"
  }'
```

### Получение JWT токена
```bash
curl -X POST http://127.0.0.1:8000/api/users/login/ \
  -H "Content-Type: application/json" \
  -d '{
    "username": "student",
    "password": "student123"
  }'
```

### Получение списка курсов
```bash
curl http://127.0.0.1:8000/api/courses/
```

### Запись на курс (требуется токен)
```bash
curl -X POST http://127.0.0.1:8000/api/courses/python-beginners/enroll/ \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

## 🌐 Доступ с других устройств

Чтобы открыть сайт на другом устройстве в локальной сети:

1. Узнайте свой IP:
```bash
ipconfig
```

2. Запустите сервер:
```bash
python manage.py runserver 0.0.0.0:8000
```

3. Добавьте IP в settings.py:
```python
ALLOWED_HOSTS = ['localhost', '127.0.0.1', 'ВАШ_IP']
```

4. Откройте на другом устройстве: `http://ВАШ_IP:8000`
